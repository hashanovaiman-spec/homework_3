# Поиск авиабилетов

Учебный проект на React, TypeScript и Redux Toolkit.

## Запуск

```bash
npm install
npm run dev
```

Также проект запускается командой:

```bash
npm start
```

Сборка:

```bash
npm run build
```

## Что реализовано

- загрузка данных через `createAsyncThunk`;
- хранение билетов через `createEntityAdapter`;
- сортировка по цене, времени в пути и оптимальности;
- фильтры по авиакомпаниям и количеству пересадок;
- адаптивная версия для десктопа и мобильных устройств;
- проверка структуры данных, полученных из API, до помещения в Redux;
- БЭМ-именование CSS-классов.

Фейковый API расположен в `public/api/tickets.json` и запрашивается через `fetch`.
